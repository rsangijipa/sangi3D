# # 073 — Jardim dos Caminhos Possíveis

Experiência 3D contemplativa em Three.js r187 WebGL com trilhas bifurcadas, pontes sobre riacho e placas personalizáveis. Permite criar novas ramificações, explorar decisões sem avaliação automática, retornar livremente (`Voltar`) para experimentar rotas alternativas e escrever/apagar anotações pessoais.

## Ferramentas

- **Criar caminho**: Abre uma nova trilha e clareira com placa de madeira a partir do ponto atual.
- **Escolha**: Lista as bifurcações disponíveis sem juízo nem pontuação (`T02`).
- **Voltar (`B` / `Backspace`)**: Retorna à bifurcação anterior para explorar outro caminho (`T01`).
- **Anotar**: Personaliza o texto da placa 3D e guarda anotações opcionais apagáveis (`T03`).
- **Elevada / Caminhada**: Alterna entre vista panorâmica do grafo e perspectiva próxima do caminhante.
