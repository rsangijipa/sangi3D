Como explorar

Seu próprio microclima

Arraste a paisagem para orbitar (3D) e use a roda do mouse ou dois dedos para aproximar. Os controles alteram o clima continuamente. Chuva umedece o terreno e neve acumula; o sol favorece a secagem e o derretimento.

Compare mundos guardando uma versão A, ajuste a versão B e alterne entre elas. Fotografe a paisagem ou exporte um JSON para reabrir. Use H para esconder controles, Esc para fechar painéis e Tab para navegar.

Modelo visual e educacional aproximado, não uma previsão meteorológica. O HTML carrega Three.js pela internet; se falhar, a paisagem 2D continua funcional.
