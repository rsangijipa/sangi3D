# Créditos e Procedência de Assets — Porto das Decisões (Projeto 10/17)

## Origem e Licenças
- **Geometria 3D:** Modelagem procedural nativa em Three.js (`src/scene/`), desenvolvida especificamente para o projeto conforme o mockup de referência visual.
- **Materiais e Texturas:** PBR gerado proceduralmente via WebGL Canvas2D (normais de ondas, madeiras, feltros, pedras e cerâmica esmaltada).
- **Design Visual & Mockup:** Baseado no arquivo `mockup.png` de produção (diorama artesanal isométrico).
- **Áudio:** 100% sintetizado em tempo real com Web Audio API (`src/audio/soundEngine.ts`) — osciladores, filtros biquad e geradores de ruído rosa calibrados para sons náuticos (ondas, buzinas de navio, sino de cais, gaivotas, motor a diesel e guindaste). Sem dependências de arquivos de áudio externos.
- **Tipografia:** Fallbacks de sistema de alta qualidade: `Georgia`, `Playfair Display` para serifada editorial e sans humanista arredondada do sistema (`system-ui`, `-apple-system`).
